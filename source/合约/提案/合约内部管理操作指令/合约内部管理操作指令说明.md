
|      |                       |      |
| ---- | --------------------- | ---- |
| C    | 新增                  |      |
| R    | 读取 （暂时都不支持） |      |
| U    | 更新                  |      |
| D    | 删除                  |      |

|      | 操作的对象                    | 支持的操作 | 格式                           |
| ---- | ----------------------------- | ---------- | ------------------------------ |
| T    | 投票阈值                      | U          | UT【整数】                     |
| P    | 模式（黑/白名单）0：白，1：黑 | U          | UP【0/1】                      |
| B    | 黑名单                        | C,D        | 【C/D】B【账户地址】           |
| W    | 白名单                        | C,D        | 【C/D】W【账户地址】           |
| M    | 管理者                        | C,U,D      | 【C/U/D】M【账户地址】【整数】 |

>T: 小于等于10为通过率模式，大于10阈值模式
